# Augmatic Holdings — website

Public site for **Augmatic Holdings LLC** → [augmaticholdings.com](https://augmaticholdings.com)

## Local

```bash
npm start
```

## Railway

1. New project → Deploy from GitHub → this repo  
2. Add custom domain `augmaticholdings.com` (and `www` if you want)  
3. At GoDaddy/Cloudflare, point DNS **A/CNAME** to Railway (or CNAME `www` + Railway domain instructions)

Start command is already in `package.json` (`serve` on `$PORT`).
